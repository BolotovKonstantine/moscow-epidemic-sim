# Генерация жителей ядром (#38)

Замер генерации синтетических жителей чистым C++ ядром ([#38](https://github.com/BolotovKonstantine/moscow-epidemic-sim/issues/38)) на полном пакете. Правила генерации — [docs/population.md](../../docs/population.md), случайность и ID — [docs/sim-core.md](../../docs/sim-core.md). Код — `native/src/core/population.cpp`, инструмент — [population.cpp](population.cpp). В отличие от прототипа [population_gen](../population_gen/README.md), вход берётся из расчётных таблиц пакета (`buildings`, `census_*`), а назначения мест (#41) здесь нет: у ролей с регулярным местом стоит метка «ещё не назначено».

## Что меряется и проверяется

- Время `generate_population`: калибровка по выборке зданий, размеры семей и смещения, состав семей, возраст, роли и профили. Один поток.
- Память колонок жителя и смещений CSR (семьи, здания) — точный размер массивов и прирост `phys_footprint`.
- Сверка с пакетом: жителей каждого здания и каждой зоны ровно столько, сколько в `buildings.residents` и `zones.residents`; жителей вне зон нет.
- Инварианты `check_population`: семья целиком в одном здании, в каждой семье есть взрослый, разница «главный взрослый — старший ребёнок» не меньше заданной, коды возраста, роли и профиля в диапазоне и связаны с возрастом, место — по роли.
- Детерминизм: повтор с тем же seed и обход зданий в обратном порядке дают побитово то же население (хеш FNV-1a всех колонок), seed + 1 — другое.
- Отклонения от переписи по территории: 5-летние группы возраста, доля детей, размеры домохозяйств, число жителей по ролям.

Нарушение любой проверки — ненулевой код возврата.

## Запуск

Из корня репозитория, пакет собирается пайплайном (`tools/city_pipeline/AGENTS.md`):

```sh
benchmarks/population/run.sh                                    # moscow-2021 0.7.0, seed 20261013
benchmarks/population/run.sh data/packages/moscow-2021-0.7.0 7  # другой seed
```

### Ограничения

- Один поток; параллельная генерация не нужна при 3,5 с, но допустима без смены результата (зависит только от номеров здания, семьи и члена семьи).
- Совпадение между платформами не проверялось: калибровка и разница возраста партнёров считаются в `double` (`sqrt`, `lround`, `llround`).
- Холодный старт, телефон и Windows не мерялись.
- Ограничения данных — те же, что у прототипа ([population_gen](../population_gen/README.md#ограничения)): несогласованность таблиц переписи, обрезка последней семьи в малых домах, доли среди указавших ответ.
