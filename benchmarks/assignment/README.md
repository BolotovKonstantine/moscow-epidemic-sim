# Замер назначения мест (#41)

Назначение мест работы и учёбы ядром на полном населении пакета: оценка вместимости мест, матрица времени между блоками 2 км по графам #42, гравитационный выбор «остаток × exp(−t/τ)», проверка пути каждого назначения планировщиком #42 и повторные назначения, коллективы мест. Правила — [docs/population.md](../../docs/population.md#вместимость-и-назначение-мест), код — `native/src/core/assignment.cpp`.

## Запуск

```sh
benchmarks/assignment/run.sh [каталог пакета] [seed] [потоки] [потоки для сравнения]
```

По умолчанию — `data/packages/moscow-2021-0.7.0`, seed населения 20261013 (seed мест — seed + 6), все ядра. Четвёртый аргумент повторяет назначение с другим числом потоков и сравнивает хеш (`assignment_hash`). Скрипт собирает release-сборку чистого ядра через CMake и печатает устройство, ОС, коммит, отчёт в JSON и вывод `/usr/bin/time -l`. Код возврата 1 — нарушены инварианты `check_assignment`.

## Выводы и ограничения

- **Достижимость.** Прототип #35 оставлял 1,02 млн поездок без пути. Теперь у каждого назначенного жителя путь есть, а без места из-за недостижимости остаются 32,5 тыс. жителей (0,25%), больше всего — студенты (25,4 тыс.): 744 колледжа и вуза собраны в немногих блоках, и у части домов без машины до них нет пути. Повторное назначение понадобилось 18,3 тыс. жителям.
- **Время в пути — следствие параметров, а не калибровка.** τ (30 мин для работы и вузов, 10 мин для садов и школ) — `game_setting`. Среднее время до сада 38 мин, а до школы 35 мин — много для детей. Причина в данных: в OSM-2021 только 3753 детских сада и 2731 школа, поэтому вместимость сосредоточена в немногих зданиях, а ближайшие места быстро заполняются. Калибровка по городскому ритму — с расписаниями #43 ([model.md](../../docs/model.md#калибровка-и-проверки)).
- **Время старта.** Назначение (134 с) добавляется к подготовке поездок #42 (141–145 с), и больше половины его уходит на проверку путей. Это та же работа, что планирование утренних поездок в #43. Если #43 возьмёт планы из проверки и сохранит их на диске по хешу пакета, параметров и seed, повторный старт займёт секунды.
- Распределения по 10-минутным интервалам — в JSON отчёта (`travel_10min`).
