# Прототип генерации жителей (#34)

Сравнительный прототип для решения [#34](https://github.com/BolotovKonstantine/moscow-epidemic-sim/issues/34): можно ли создать всех жителей региона при старте ядра из пакета, демографических ограничений и seed. Правила генерации — в [docs/population.md](../../docs/population.md), общие правила замеров — в [../README.md](../README.md). Это не код ядра: генерация (#38) и назначение мест (#41) пишутся заново по правилам документа, с тестами.

## Что проверяется

- **Числа переписи.** [census.py](census.py) читает пять таблиц Росстата из `data/raw/`. Перед чтением он сверяет SHA256 с реестром `data/manifests/sources.json` и пишет `census.json` со строками «г. Москва» и «Московская область». Нужна только стандартная библиотека Python.
- **Вход генератора.** [prepare.py](prepare.py) переводит пакет, `census.json` и [params.json](params.json) в сырые массивы и текст `params.txt`: доли по году возраста, размеры семей, число детей, доли обучения и занятости, веса рабочих мест зданий, учреждения. Это не формат пакета (#36).
- **Генерация** ([gen.cpp](gen.cpp)): калибровка по выборке зданий, затем размеры семей, префиксные суммы ID, состав и возраст, роли, профили. Меряются время и прирост `phys_footprint`. Проверяется точное число жителей каждого здания, целостность семей, наличие взрослого и разница возраста с детьми. Отклонения возраста, размеров семей и ролей сравниваются с переписью.
- **Независимость от порядка:** население, созданное обходом зданий в обратном порядке, должно совпасть побитово (хеш FNV-1a колонок).
- **Места:** оценка вместимости из спроса и площади, назначение по кольцам зон, учёт дефицита и нуля мест.
- **Малые сцены** (`gen <вход> --selftest`): четыре зоны, 258 жителей, нет детских садов, школ вдвое меньше спроса, работа только в дальней зоне; вторая сцена — без рабочих мест вовсе. Параметры демографии берутся из входа.

## Запуск

Таблицы переписи скачиваются один раз в `data/raw/` по адресам из карточек `rosstat-vpn2020-*` реестра. Команда `fetch` пайплайна берёт только источники конфигурации сборки, а эти таблицы пока в неё не входят.

```sh
.venv/bin/python -c 'import json; [print(s["url"], s["file"]) for s in json.load(open("data/manifests/sources.json"))["sources"] if s["source_id"].startswith("rosstat-")]' \
  | while read url file; do curl -sfL -o "data/raw/$file" "$url"; done
benchmarks/population_gen/run.sh data/packages/moscow-2021-0.5.0 build/bench/population_gen/full
```

Мини-город тестов пайплайна (1671 житель):

```sh
.venv/bin/python benchmarks/population_gen/mini_city.py build/bench/population_gen/mini-pkg
benchmarks/population_gen/run.sh build/bench/population_gen/mini-pkg build/bench/population_gen/mini
```

### Ограничения

- Таблицы домохозяйств и возраста переписи не согласованы (см. [docs/population.md](../../docs/population.md#источники-и-виды-значений)), поэтому доля семей с детьми калибруется.
- Обрезка последней семьи в малых домах увеличивает долю одиночек в поясе на 3,3 п.п.
- Доли обучения и занятости взяты среди указавших ответ. Отсутствовавшие в переписи ответы (около трети в Москве) считаются такими же. Подростки 15–17 лет работают с долей среди не учащихся, как и взрослые. Число работающих в Москве — 7,5 млн; с независимыми оценками оно не сверялось.
- Назначение мест — по кольцам зон и прямой дистанции, а не по графу; это прототип, а не модель спроса #41. `exp` и `log` из libm используются только для желаемого расстояния; совпадение между платформами не проверялось.
- Холодный старт и телефон не мерялись.
