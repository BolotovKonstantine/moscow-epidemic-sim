# Загрузка расчётного пакета ядром

Замер для [#37](https://github.com/BolotovKonstantine/moscow-epidemic-sim/issues/37): сколько времени чистое C++ ядро (`native/src/core`, без Godot) читает и проверяет таблицы `sim/` пакета и сколько памяти они занимают. Правила проверки — [docs/sim-core.md](../../docs/sim-core.md#расчётный-пакет).

`load_city.cpp` загружает пакет несколько раз подряд в один `CityData` через `load_city_package`: паспорт, индекс, размер и SHA256 каждой таблицы, заголовки, колонки по схеме, значения (коды, диапазоны, ссылки, CSR). Для каждой загрузки печатаются время, память буферов таблиц и пик резидентной памяти процесса. Пик не растёт с числом повторов — прежние таблицы освобождаются перед новой загрузкой.

## Запуск

Из корня репозитория, нужен собранный пакет (вне Git):

```sh
benchmarks/city_load/run.sh                                        # moscow-2021 0.7.0, 5 повторов
benchmarks/city_load/run.sh data/packages/moscow-2021-0.7.0 10
```

Скрипт собирает release-версию ядра через CMake (`native/build/core`, вне Git) и печатает процессор, память, версию macOS и коммит.

## Результат

17 октября 2026, эталонный Mac (M1, 16 ГБ, macOS 26.5.1, от сети), коммит `fce63d0` с изменениями #37, release-сборка clang (`-O2`, CMake `Release`), пакет `moscow-2021` 0.7.0 (20 таблиц, 76 МБ файлов):

| Показатель | Значение |
| --- | --- |
| Первая загрузка | 115–150 мс |
| Повторные загрузки (файлы в кеше ОС) | 59–64 мс |
| Память буферов таблиц | 79,8 МБ (файлы плюс 64 байта выравнивания на таблицу) |
| Пик резидентной памяти процесса | 82 МБ после 5 загрузок, растёт на 0,1 МБ за повтор (куча, не таблицы) |
| SHA256 | CommonCrypto |

С переносимой реализацией SHA256 (та же сборка GCC 16 без ветки Apple) загрузка занимает 560–660 мс: почти всё время уходит на хеш. Поэтому контракт требует системную реализацию на каждой платформе; на Windows (BCrypt) она появится вместе со сборкой Windows.

Мини-город `tests/fixtures/sim_mini` (127 КБ) через мост Godot загружается за ~4 мс (debug-сборка, дымовой тест `tests/integration/smoke_native.gd`).
