# Дополнительно для Claude Code

Общие правила проекта — в [AGENTS.md](AGENTS.md) (импортирован выше). Новые общие правила добавляй туда, а сюда — только то, что касается Claude Code.

- В модулях (`game/`, `native/`, `tools/city_pipeline/`) правила хранятся в `AGENTS.md` подкаталога; рядом лежит `CLAUDE.md` с одной строкой `@AGENTS.md`, чтобы Claude Code подхватывал их автоматически.
- Godot-проект проверяй через headless-запуск (`godot --headless`), а не открытием редактора.
- Если задача упирается в открытый вопрос из [docs/decisions.md](docs/decisions.md) (эталонные ПК и iPhone, год сценария, автономность пакета и др.), задай вопрос автору, а не выбирай молча.
