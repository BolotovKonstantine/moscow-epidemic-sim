# game/ — клиент Godot

Общие правила — в [../AGENTS.md](../AGENTS.md). Godot 4.7.2 stable, renderer Compatibility (`gl_compatibility`, в том числе для мобильных).

## Устройство

- `scenes/` — сцены; `scripts/app/` — сессия и запуск; остальные каталоги из [docs/architecture.md](../docs/architecture.md) создаются по мере надобности.
- `bin/mesim.gdextension` — описание нативной библиотеки (в Git); сами библиотеки в `bin/` собираются из `native/` и в Git не попадают.
- Файлы `*.uid` создаёт Godot — их коммитим. `.godot/` — кеш, не коммитим.
- Жители, здания и группы — данные ядра, а не Nodes.
- `scripts/map/` — карта из участков `.mtile` ([формат](../docs/city-package.md#участки-карты)): `MapIndex` и `MapTile` читают и проверяют индекс и участки (версия, SHA256, пакет, границы разделов; ошибка — текст, а не падение), `MapTileView` строит пять мешей и фон на участок (число узлов не зависит от числа зданий; массивы мешей готовятся вне основного потока), `MapView` — камера, зум, уровни подробности и видимость участков, `MapTileStreamer` — подгрузка участков по камере (#14, см. ниже), `MapTheme` — все цвета и толщины (решение #10), `MapLineStyle` и `shaders/map_line.gdshader` — ширина лент линий по классу и масштабу, `MapLabelLayer` — все подписи одним узлом: по приоритету темы, в диапазоне масштаба класса (подписи участков 8 и 2 км — только на своём уровне), без пересечений, не больше `MapTheme.LABEL_MAX` за кадр; подпись вдоль линии показывается, только если помещается в её прямой участок.
- Выбор здания (#15): `MapPick` — данные выбора участка 2 км (кольца, прямоугольники, колонки карточки; создаётся в `MapTileView.prepare` вне основного потока, вершины общие с мешем зданий), `MapView.building_at` / `select_at` — здание под точкой и выбор по клику без перетаскивания (сдвиг больше `CLICK_SLOP_PX`), подсветка контура — узел `Selection` поверх участков, цвета — `MapTheme.SELECTION*`. Выбирать можно только на уровне подробности 2; клик мимо зданий снимает выбор, а пока грузится участок 2 км, чей охват по индексу содержит точку (здание соседа может выступать за край), клик выбор не меняет; Esc снимает выбор. Правило попадания и наложения — в [docs/city-package.md](../docs/city-package.md#участки-карты). `scripts/ui/building_card.gd` (`BuildingCard`) — карточка справа: оценки (в том числе связь с учреждениями) курсивом с пометкой «оценка», пропуски — `unknown`.
- Подгрузка участков (#14): при старте загружены индекс и обзор региона; участки 8 или 2 км (по масштабу) нужны, если задевают окно с запасом `PREFETCH` (четверть окна с каждой стороны), и грузятся от центра к краям. Чтение, SHA256, распаковка и массивы мешей — в `WorkerThreadPool` (до `MAX_IN_FLIGHT` участков), узлы создаёт основной поток в `_process`, пока не потратит `ATTACH_BUDGET_USEC` за кадр (хотя бы один участок). Загруженные участки — кеш с вытеснением давно не нужных (LRU); память кеша — оценка `MapTileView.data_bytes` (массивы мешей, подписей и данных выбора, без GPU-копий) — не превышает лимит: участок, которому нет места даже после вытеснения ненужных, не подключается, вместо него виден уровень ниже. Пока участок 2 км не подключён, под ним виден загруженный участок 8 км, иначе обзор. Подписи участков хранятся блоками и выгружаются вместе с участком. Лимит — игровая настройка (`MapTileStreamer.DEFAULT_LIMIT_MB` = 256 МБ, `--map-cache-mb=<МБ>`).
- Главная сцена берёт участки из `--map-dir=<путь>` (после `--`), иначе из `map/` пакета с наибольшей версией в `../data/packages/`, иначе из `../data/processed/map-test` (их пишет `city_pipeline map-tile`). Без участков показывает подсказку с командой сборки. F3 — отладочный оверлей (в отладочной сборке включён по умолчанию): загруженные и видимые участки, загрузки, кеш и его пик, худший кадр за секунду, время загрузчика в основном потоке, статическая и видеопамять.

## Команды (из корня репозитория)

```sh
godot --headless --path game --import                                       # первичный импорт / обновление кеша
godot --headless --path game --script ../tests/integration/smoke_native.gd  # дымовой тест моста
godot --headless --path game --script ../tests/integration/map_tile_loader.gd  # загрузчик участков карты
godot --headless --path game --script ../tests/integration/map_streaming.gd    # подгрузка участков по камере
godot --headless --path game --script ../tests/integration/map_pick.gd         # выбор зданий и карточка
godot --path game                                                           # запустить приложение (карта)
godot --path game -- --map-dir=/путь/к/участкам                             # другой каталог участков
godot --path game -- --map-cache-mb=64                                      # другой лимит кеша участков
godot --headless --path game --export-debug "macOS" ../build/exports/macos/MoscowEpidemicSim.app
godot --headless --path game --export-release "macOS" ../build/exports/macos-release/MoscowEpidemicSim.app
```

Тест загрузчика читает синтетический набор `tests/fixtures/map_tile/` (его пишет Python-код экспорта, см. [tools/city_pipeline/AGENTS.md](../tools/city_pipeline/AGENTS.md)), проверяет отказ на повреждённых файлах, выбор подписей по масштабу и без пересечений и, если есть `data/processed/map-test/`, загружает настоящий экспорт и печатает время и память. Тест подгрузки облетает синтетический регион 12×12 км `tests/fixtures/map_stream/` (обзор, 4 участка 8 км, 36 участков 2 км; пишет тот же `map_fixture.py`) с лимитом меньше всего набора — сразу и в фоновых потоках: кеш не превышает лимит, набор ни разу не загружен целиком, видимые участки догружаются, выгруженные узлы и их подписи освобождаются, слишком маленький лимит оставляет только обзор. Если есть пакет с картой в `data/packages/`, тест облетает и его (лимит 64 МБ) и печатает время основного потока за кадр с подключением. Замер на эталонном Mac (M1, 16 ГБ, headless, `moscow-2021` 0.2.0, 11 октября 2026): 243 подключения и 79 вытеснений, пик кеша 64 МБ из 64; основной поток за кадр с подключением — медиана 0,3–0,7 мс, 95 % — 1,3–2,2 мс, худший кадр обычно 2,7–5,7 мс, в 2 из 9 прогонов — 13–15 мс (единичное подключение участка); чтение участка в рабочем потоке — 50–200 мс. Отрисовка и раскладка подписей в этот замер не входят: полный замер кадра — #17. Тест выбора проверяет попадание, двор, промах, правило наложения, здание за краем участка, выбор после выгрузки участка, клик по ещё не загруженному участку и текст карточки (оценки, `unknown`); если есть пакет с картой, выбирает по точке внутри ~100 зданий в каждом из трёх самых тяжёлых участков 2 км и сверяет ID, функцию, этажность, площадь и зону с `building_attributes.csv.gz`. Управление картой: колесо или щипок — масштаб вокруг курсора, перетаскивание или прокрутка двумя пальцами — сдвиг, Ctrl/Cmd + прокрутка, `+`/`-` — масштаб, `0` — весь регион, клик (вблизи) — карточка здания, Esc — снять выбор. Предел приближения — 0,25 м на пиксель.

Перед запуском нужна собранная библиотека (см. [../native/AGENTS.md](../native/AGENTS.md)); без неё главная сцена покажет ошибку загрузки ядра. Для экспорта нужны шаблоны Godot 4.7.2 (`~/Library/Application Support/Godot/export_templates/4.7.2.stable/`) и библиотека нужной сборки: `--export-debug` берёт `template_debug`, `--export-release` — `template_release`. Пресет `macOS` (`export_presets.cfg`): universal, ad-hoc подпись, без нотаризации; минимальная macOS — 11 (Intel) и 13 (Apple Silicon), как требует Godot 4.7. Библиотека ядра собирается с `macos_deployment_target=11.0` (см. `native/SConstruct`); проверка — `vtool -show-build` по бинарнику в `.app`. Предупреждение про Info.plist у framework безвредно: Godot создаёт его сам. Экспорт требует `textures/vram_compression/import_etc2_astc=true`. `build/` вне Git.
