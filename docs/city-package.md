# Формат паспорта городского пакета

На этапе 0 реализован паспорт версии 1: JSON с описанием региона, происхождением данных и перечнем файлов. Схема и CLI находятся в `tools/city_pipeline/`. Паспорт не содержит население или геометрию целиком: большие данные лежат рядом отдельными файлами, а проверка SHA256 читает их блоками.

Паспорт создаёт контракт между подготовкой данных и будущим загрузчиком игры. Сейчас загрузчик Godot и бинарные форматы таблиц ещё не реализованы. Успешная проверка паспорта не означает, что пакет готов к игровой партии.

## Поля паспорта версии 1

| Поле | Значение |
| --- | --- |
| `schema_version` | Целое число 1; несовместимая версия отклоняется |
| `package_id`, `package_version` | Идентификатор пакета и версия его содержимого |
| `kind` | `fixture` для технического примера, `city_data` для подготовленных городских данных |
| `description` | Описание покрытия и назначения |
| `created_at` | Время создания с часовым поясом |
| `builder` | Имя и версия инструмента подготовки |
| `region` | Правило региона, 30 км буфера, системы координат и ссылка на файл границы |
| `sources` | Карточки происхождения исходников |
| `assets` | Файлы пакета, их роли, размеры, хеши и связи с источниками |

Схема: [city-package-v1.schema.json](../tools/city_pipeline/schemas/city-package-v1.schema.json). Поля с неизвестными именами отклоняются, чтобы опечатка не выглядела принятой настройкой. Версия схемы независима от версий пакета, ядра и Godot.

## Регион и координаты

`region.rule` фиксирует правило `moscow_admin_union_mkad_outer_buffer`; `buffer_meters` равен 30000. `storage_crs` — `EPSG:4326`, порядок географических координат — долгота, широта. `metric_crs` описывает выбранную метрическую проекцию обработки. `boundary_asset_id` указывает на существующий элемент `assets` с ролью `boundary`.

Это декларация правил обработки. Валидатор пока не проверяет, что контур действительно построен как объединение административной Москвы с буфером МКАД, что проекция метрическая или что координаты геометрии корректны. Проверка этих свойств относится к географическому пайплайну этапа 1 и должна быть добавлена вместе с ним.

В тестовом примере проекция обозначена как не выбранная: метрические операции в нём не выполняются. Для реального пакета нужно выбрать проекцию, получить контуры и указать источники и даты. Год игрового сценария паспорт не выбирает автоматически; он будет частью отдельной конфигурации сценария.

## Источники и файлы

Каждая карточка источника содержит ID, тип `external` или `synthetic`, URL, владельца, лицензию, дату данных, время получения, покрытие, формат, SHA256 исходника и версию обработки. Неизвестная дата данных обозначается `null`; хеш и лицензия необходимы для подготовленного пакета и не заменяются выдуманными значениями.

Файл содержит ID, роль, относительный путь, формат, размер в байтах, SHA256 и ссылки на источники. Путь записывается с `/` относительно каталога паспорта. Абсолютные пути, `..`, обратные слеши, неоднозначные компоненты и ссылки за пределы пакета не принимаются. Большие исходные выгрузки не обязаны лежать в пакете: их хеш сохраняется в карточке происхождения.

`data_kind` разделяет `observed`, `estimated` и `game_setting`. Для `estimated` обязательны `estimation.method` и `estimation.uncertainty`. Синтетический источник не может обосновывать файл с видом `observed`. Неизвестные значения внутри будущих таблиц должны иметь явное представление; их правила появятся вместе с форматами таблиц.

Роли файлов: граница, здания, дороги, транспорт, учреждения, население и отчёт качества. Набор доступных слоёв может быть неполным на промежуточных этапах. Валидатор не объявляет такой пакет играбельным и не подставляет отсутствующие слои нулевыми значениями.

## Проверки

CLI проверяет версию и обязательные поля, даты, уникальность ID и путей, связи с источниками и файл границы. В полном режиме дополнительно проверяются наличие, размер и SHA256 всех перечисленных файлов. JSON с повторяющимися ключами, NaN и Infinity отклоняется.

`--metadata-only` позволяет проверить паспорт до размещения больших файлов. Вывод явно указывает, что содержимое файлов не проверялось. Геометрия, связность графа, лицензирование производной базы и качество населения этой командой не подтверждаются.

Команды установки, проверки и тестов приведены в [AGENTS.md пайплайна](../tools/city_pipeline/AGENTS.md).
