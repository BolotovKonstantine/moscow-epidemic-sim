# Участие в проекте

Проект находится на этапе планирования. Сейчас полезны предложения по модели, проверяемые источники городских данных, уточнение архитектуры и небольшие технические эксперименты. Основные требования собраны в [решениях проекта](docs/decisions.md), этапы — в [плане разработки](docs/roadmap.md).

## Предложения и изменения

Для предложения создайте GitHub Issue с описанием задачи, ожидаемого результата и способа проверки. Для нового источника данных укажите владельца, ссылку, дату, покрытие и условия использования. Предположения модели должны отличаться от наблюдаемых данных.

Для изменения создайте fork и отдельную ветку, затем откройте pull request. В описании объясните, что изменилось, зачем и как проверялось. Крупные новые механики сначала обсудите в Issue, чтобы согласовать их с масштабом и платформами проекта.

Документация ведётся на русском языке. Названия файлов и программные идентификаторы могут быть на английском. В репозитории пока нет готового приложения; команды сборки будут добавлены вместе с техническим прототипом.

Общие правила для ИИ-ассистентов разработки (инварианты модели, правила данных, соглашения) собраны в [AGENTS.md](AGENTS.md); они полезны и при ручной разработке.

## Данные и лицензия

Собственный код и документация распространяются по [лицензии MIT](LICENSE). Сторонние геоданные, библиотеки и ресурсы сохраняют собственные лицензии. MIT проекта не заменяет условия OpenStreetMap и других источников.

Большие выгрузки города, промежуточные данные и собранные пакеты хранятся отдельно. В репозитории сохраняются способы получения, манифесты и небольшие разрешённые тестовые наборы. Локальные секреты и персональные записи реальных жителей в проект не добавляются; население синтетическое.
